Overview
This repository contains the website project for Lagoqoza School Transport, a small, community-based school transport business founded by Faith Khulile Masombuka.

The website's purpose is to give Lagoqoza School Transport an online presence, letting parents learn about the service and submit enquiries, rather than relying only on word of mouth.

Website Goals and Objectives
Generate new enquiries from parents looking for school transport.
Build trust by clearly communicating the service's story, mission, and reliability.
Give parents and schools an easy way to make an enquiry.

Key Features and Functionality
Five pages: Home, About Us, Services & Pricing, Enquiry, and Contact.
A client-side validated enquiry form.
Consistent navigation with active-page indication (`.active` class) across all pages.

Part 1 Details
Website Project Proposal.
Five HTML pages (`index.html`, `about.html`, `services.html`, `enquiry.html`, `contact.html`) with semantic structure, navigation, and integrated content.

Part 2 Details
CSS styling for the desktop solution
External stylesheet (`newcss.css`) linked from every page
CSS reset (`box-sizing: border-box`), consistent colour scheme and typography via CSS custom properties (`:root`).
Layout structure: CSS Grid (`.hero`, `.intro-grid`, `.route-banner`, `.three-up` cards, `.site-footer` — including `grid-template-areas` on the footer) and Flexbox (`.site-header`, `.button-row`)
Visual styles: `color`, `background-color`, `border`, and `box-shadow` (cards, buttons, the CSS-drawn bus). Interactive states covered with `:hover`, `:focus-visible`, and `:active` on all nav links, buttons, and the mobile menu
